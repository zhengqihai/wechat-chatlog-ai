# Chatlog AI 便携统一版

Chatlog AI 在本机启动微信、QQ 数据读取服务，并在同一个网页中显示真实会话和聊天记录。选择会话后，可把当前筛选范围内的文本发送给 AI 模型做总结、待办提取或继续问答。支持 DeepSeek、Kimi（Moonshot）、智谱 GLM、通义千问等国内模型，以及任意 OpenAI 兼容的自定义接口，模型与 API Key 均可在网页中配置。发行包已包含 Node.js 与 Python 运行时，对方不需要另行安装开发环境。

## 本机使用

1. 保持需要使用的平台客户端已登录，双击 `启动Chatlog-AI.bat`。
2. 等待浏览器自动打开 `http://127.0.0.1:18765`。
3. 首次进入会自动弹出“模型与 API Key 设置”窗口，选择模型供应商并填写 API Key，验证通过后保存（详见下文“模型配置”）。
4. 左侧切换微信或 QQ 并选择真实会话，中间设置时间和消息范围，右侧向 AI 提问或生成分析。
5. 使用完毕后关闭启动窗口、按 `Ctrl+C`，或点击网页左上角退出按钮。本次启动创建的三个本地服务会一起结束，但不会关闭微信或 QQ 客户端。

## 模型配置

模型供应商与 API Key 全部在网页中配置，无需手动编辑 `config.json`。

1. 点击页面右上角“模型设置”，或在首次进入时自动弹出的窗口中操作。
2. 选择“供应商类型”（DeepSeek / Kimi / 智谱 GLM / 通义千问 / 自定义），会自动带出对应的 Base URL 与默认模型名。
3. 填写 API Key 后点击“验证 Key”，程序会真实调用一次接口确认 Key 可用，验证通过后才能保存。
4. 可添加多个供应商，并在列表中点击“使用”切换当前生效的模型；生成分析与自动回复都使用当前模型。
5. 页面右上角“刷新余额”可查询当前账户余额（DeepSeek、Kimi 支持；智谱 GLM、通义千问、自定义暂不支持）。

保存后的 API Key 会写入根目录 `config.json`，页面仅显示脱敏形式。请勿把该文件发给别人。

## 消息范围

- 时间支持“不限制”以及最近 N 分钟、N 小时、N 天。
- 消息支持“最近 N 条”以及“不限制（最多读取 2000 条）”。默认读取最近 500 条。
- 整合层最多读取 2000 条：微信按上游每页最多 500 条分页，QQ 按上游每页最多 200 条分页。
- 2000 是本工具为交互速度和模型成本设置的读取上限，不代表微信或 QQ 数据库只有 2000 条。
- 实际发送给模型的是时间与条数两个条件共同筛选后的消息。消息越多，请求越慢，消耗的模型 Token 和费用也越高。

## 新电脑首次初始化

聊天数据库密钥与登录设备绑定，不能从其他人的电脑复制，也不能包含在分享包中。首次使用某个平台前，必须在本机完成该平台授权：

1. 安装并登录需要使用的微信或 QQ 客户端，确保本机已有聊天记录。
2. 右键 `首次初始化.bat`，选择“以管理员身份运行”。
3. 初始化程序先检查已有授权，只打开尚未完成的平台页面。微信已完成时不会重复打开微信页面，QQ 同理。
4. 在上游页面按提示检测当前账号、获取并验证数据库密钥。QQ 页面首次进入时需要填写初始化窗口显示的本机访问令牌。
5. 授权文件保存后，初始化窗口会明确显示该平台已完成及剩余步骤。
6. 完成所需平台后，关闭“首次初始化”窗口，再双击 `启动Chatlog-AI.bat`。不能只关闭浏览器，否则初始化服务仍会占用本地端口。

只使用微信或只使用 QQ 都可以，不要求两个客户端同时登录。第一次仅完成微信后，以后首次使用 QQ 时需要再次运行初始化；程序会跳过微信，只打开 QQ。两个平台都完成后，通常不必重复初始化。客户端大版本升级、账号数据目录变化或密钥失效时，才需要重新授权。

密钥提取是上游解析器的能力，受客户端版本、进程权限和安全软件影响。涉及进程检查、客户端重启或系统授权的步骤必须由用户确认，整合程序不能静默绕过。失败时先确认客户端版本与本文“已验证版本”一致，并查看 `logs` 目录。

## 分享给别人

直接发送 `release\Chatlog-AI-portable.zip`。不要把整个个人使用目录压缩后发送，因为个人目录的 `data` 中包含本机数据库密钥和聊天缓存，`config.json` 会保存模型 API Key，`logs` 也可能含账号路径。

对方解压到普通可写目录后，只需：

1. 登录其要使用的平台，并完成该平台的首次初始化。
2. 关闭初始化窗口，双击 `启动Chatlog-AI.bat`。
3. 在页面中配置模型供应商与 API Key 即可使用。

## 数据与隐私

- 本程序只读取本机已有聊天数据库，不发送微信或 QQ 消息，也不修改客户端数据库。
- 只有点击分析或提问后，当前筛选范围内的聊天文本才会发送到当前选中的模型 API 地址。
- 图片、语音、视频、文件等非文本消息只以类型标签参与统计，不做 OCR 或语音识别。
- 所有本机密钥与缓存都在 `data`，运行日志在 `logs`，模型 API Key 保存在 `config.json`。这些文件/目录不得分享。
- 仅处理本人合法持有或已取得明确授权的数据。
