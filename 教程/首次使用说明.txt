Chatlog AI 首次使用

本工具无需再手动编辑 config.json 填写 API Key，所有 AI 模型配置都在网页里完成。

一、配置微信文件路径(非必须，可以先直接从第二步开始，若不成功再用第一步)
首次使用前，先编辑“首次初始化.bat”与“启动Chatlog-AI.bat”两个文件，在“set "PYTHONPATH=xxx”的下一行添加：
    set "WECHAT_TOOL_DATA_DIR=微信文件地址（具体查看电脑端微信“设置”-存储位置）"

二、完成平台授权（微信 / QQ）
首次使用某个平台前，先登录对应的微信或 QQ 客户端，再右键“首次初始化.bat”并选择“以管理员身份运行”。
初始化程序会自动检查已有授权，只打开尚未完成的平台。只使用微信或只使用 QQ 都可以，不要求两个客户端同时登录。

三、启动统一页面
上游页面显示授权成功后，关闭“首次初始化”窗口，再双击“启动Chatlog-AI.bat”。
浏览器会自动打开 http://127.0.0.1:18765 。不能只关闭浏览器，否则初始化服务仍在运行并占用端口。

四、配置 AI 模型（首次进入会自动弹窗）
首次进入页面时，如果还没有配置任何模型，会自动弹出“模型与 API Key 设置”窗口；以后也可以随时点击页面右上角“模型设置”按钮打开。操作步骤：

1. 在弹窗下方“添加 / 修改供应商”区域，先选择“供应商类型”：
   - DeepSeek
   - Kimi（Moonshot）
   - 智谱 GLM
   - 通义千问（DashScope）
   - 自定义（OpenAI 兼容）
   选择后会自动带出对应的 Base URL 和默认模型名，一般无需修改。

2. 如需区分多个账户，可修改“显示名称”，例如“我的 DeepSeek”“公司的 Kimi”。

3. 在“API Key”一栏粘贴你的密钥。

4. 点击“验证 Key”。程序会真实调用一次该模型的接口，确认这个 Key 可用；验证通过后“添加 / 保存”按钮才会亮起。

5. 点击“添加 / 保存”完成配置。API Key 会被保存到本机 config.json，页面只显示脱敏后的形式（如 sk-xxxx****xxxx）。

五、多个模型与切换
可以重复上面的步骤添加多个供应商。在“已配置的模型供应商”列表中，带“（当前使用）”标记的是正在生效的模型；点击某个供应商的“使用”按钮即可切换为当前模型。
生成分析和自动回复都会使用当前选中的模型。删除某个供应商时，程序会自动切换到剩余的第一个。

六、余额查询
在页面右上角“余额”旁点击“刷新余额”，即可查询当前模型账户余额（程序也会定时自动刷新）。
- 支持余额查询：DeepSeek、Kimi（Moonshot）。
- 暂不支持余额查询：智谱 GLM、通义千问（DashScope）、自定义，会显示“该供应商不支持查询”。

七、消息范围
统一页面的时间范围支持不限制、最近 N 分钟、N 小时或 N 天；消息范围支持最近 N 条或不限制。不限制消息仍最多读取 2000 条。

八、退出
关闭启动窗口、按 Ctrl+C，或点击网页左上角退出按钮，本次启动的本地服务会全部关闭。

九、分享注意事项
分享时只发送 release\Chatlog-AI-portable.zip，绝对不要发送个人目录中的 data、logs 和 config.json（config.json 中会保存已填写的模型 API Key）。

十、API Key 申请地址
   - DeepSeek：https://platform.deepseek.com/api_keys
   - Kimi（Moonshot）：https://platform.moonshot.cn/console/api-keys
   - 智谱 GLM：https://open.bigmodel.cn/usercenter/apikeys
   - 通义千问（DashScope）：https://dashscope.console.aliyun.com/apiKey


补充：现已支持多微信、QQ 互相切换，使用方式：
- 电脑切到 B 微信
- 双击 首次初始化.bat → 会打开微信/QQ 授权页 → 在页面里重新生成 B 的密钥
- 关掉初始化窗口
- 双击 启动Chatlog-AI.bat → 检测到 A、B 两个微信账号 → 控制台输入序号选择 B → 回车进入

注意：授权必须由本机用户在微信或 QQ 的安全流程中确认，程序不能静默绕过。详细说明见 README.md。
