Chatlog AI 首次使用

一、用文本编辑器打开根目录 config.json，只填写自己的 DeepSeek API Key。
二、首次使用前，先编辑“首次初始化.bat”与“启动Chatlog-AI.bat”两个文件，在“set "PYTHONPATH=xxx”的下一行添加：set "WECHAT_TOOL_DATA_DIR=微信文件地址（具体查看电脑端微信“设置”-存储位置）"，
三、首次使用某个平台前，先登录对应的微信或 QQ 客户端，再右键“首次初始化.bat”并选择“以管理员身份运行”。
四、初始化程序会自动检查已有授权，只打开尚未完成的平台。只使用微信或只使用 QQ 都可以，不要求两个客户端同时登录。
五、上游页面显示授权成功后，初始化窗口也会显示该平台已完成。关闭“首次初始化”窗口，再双击“启动Chatlog-AI.bat”。不能只关闭浏览器，否则初始化服务仍在运行并占用端口。
六、以后新登录另一个平台时，再运行一次“首次初始化.bat”；已完成的平台会自动跳过，只处理新增平台。两个平台都完成后通常无需重复初始化。
七、统一页面的时间范围支持不限制、最近 N 分钟、N 小时或 N 天；消息范围支持最近 N 条或不限制。不限制消息仍最多读取 2000 条。
八、退出时关闭启动窗口、按 Ctrl+C，或点击网页左上角退出按钮，本次启动的本地服务会全部关闭。
九、分享时只发送 release\Chatlog-AI-portable.zip，绝对不要发送个人目录中的 data、logs 和已填写 Key 的 config.json。
十、deepseek申请API-KEY地址：https://platform.deepseek.com/sign_in


注意：授权必须由本机用户在微信或 QQ 的安全流程中确认，程序不能静默绕过。详细说明见 README.md。
